# Sources and scope

Consult these sources when attribution or a deeper comparison is needed. Routine PR writing does not require fetching them.

- [HumanLayer: show-me](https://github.com/humanlayer/skills/blob/main/plugins/show-me/skills/show-me/SKILL.md) by Dex Horthy, MIT: choose a compact representation for the question, use a focused diff when context is familiar, and show a complete example when omitted context would hide ownership or order. [Representations](representations.md) adapts its menu of shapes for pull requests.
- [Matt Pocock: pr](https://github.com/mattpocock/skills/blob/main/skills/engineering/pr/SKILL.md), MIT: a Summary, Evidence, and Merge Danger template whose Summary reuses show-me's visual shapes. This skill adopts its before-and-after evidence and its door and blast-radius view of risk.

Use the representation that helps reviewers assess the change. This guidance does not require a visual artifact or an installed `show-me` skill.
